Механика и кинематика

Второй закон Ньютона
F = m·a
Кинетическая энергия
E_k = m·v² / 2

x = x₀ + v₀·t + a·t² / 2

Q = ΔU + A

Электростатика и постоянный ток

Закон Ома
I = U / R
Закон Джоуля–Ленца
Q = I²·R·t
Закон Кулона
F = k·|q₁·q₂| / r²
Правила Кирхгофа
ΣI = 0 (узел); ΣIR = ΣE (контур)

Магнетизм и электромагнетизм

Закон Фарадея
ε = −dΦ/dt
Закон Био–Савара–Лапласа
dB = (μ₀·I / 4π) · (dl × r) / r³

d·sin φ = k·λ
