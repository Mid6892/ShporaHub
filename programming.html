Работа со стеком (наглядно)

Как устроен стек (LIFO)

Стек растет вниз (от старших адресов к младшим). Регистр ESP (Stack Pointer) всегда указывает на вершину — то есть на последний добавленный элемент.

Значение EAX: 0x00000004
Значение ESP: 0x0010FFF4
push eax   ; ESP = ESP - 4, затем [ESP] = EAX
pop eax     ; EAX = [ESP], затем ESP = ESP + 4
