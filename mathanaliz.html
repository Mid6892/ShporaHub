Пределы и непрерывность

Первый замечательный предел
lim(x→0) sin(x)/x = 1
Второй замечательный предел
lim(x→∞) (1 + 1/x)^x = e
Эквивалентности при x→0
sin x ~ x, tg x ~ x, ln(1+x) ~ x, e^x−1 ~ x

Производные и дифференциалы

Производная степенной
(x^n)' = n·x^(n−1)
Производная произведения
(u·v)' = u'·v + u·v'
Производная сложной функции
[f(g(x))]' = f'(g(x))·g'(x)

Интегралы

Табличный интеграл
∫ x^n dx = x^(n+1)/(n+1) + C
Формула Ньютона–Лейбница
∫[a..b] f(x) dx = F(b) − F(a)
Интегрирование по частям
∫ u dv = u·v − ∫ v du

Ряды

Ряд Тейлора
f(x) = Σ f⁽ⁿ⁾(a)/n! · (x−a)ⁿ
Ряд Маклорена для e^x
e^x = Σ xⁿ/n! = 1 + x + x²/2! + …

Функции нескольких переменных

Частная производная
∂f/∂x = lim(Δx→0) [f(x+Δx, y) − f(x,y)] / Δx
Полный дифференциал
df = (∂f/∂x)dx + (∂f/∂y)dy
