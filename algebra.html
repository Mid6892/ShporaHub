Матрицы и определители

Определитель 2×2
|a b; c d| = ad − bc
Обратная матрица
A⁻¹ = (1/det A) · adj(A)
Определитель 3×3 (правило Саррюса)
det A = a11·a22·a33 + a12·a23·a31 + a13·a21·a32 − a13·a22·a31 − a11·a23·a32 − a12·a21·a33

Векторная алгебра

Скалярное произведение
a→·b→=|a→||b→|cosφ - работа силы по перемещению
Векторное произведение
|a→×b→|=|a→||b→|sinφ - площадь аараллелограмма
Смешанное произведение
(a→,b→,c→)=a→·(b→×c→) - объём параллелепипеда

Аналитическая геометрия

Уравнение прямой
Ax + By + C = 0
Уравнение плоскости
Ax + By + Cz + D = 0
Расстояние от точки до плоскости
d = |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²)
